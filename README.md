# Cab Booking System - SQL Capstone Project

A MySQL database project that manages cab bookings, customers, drivers, cabs and payments.
Built as a capstone project for the MySQL course at IT Vedant.

## Database Design

Tables: `Customers`, `Drivers`, `Cabs`, `Bookings`, `Payments`

## Concepts Used

* Creating databases and tables
* INSERT, UPDATE
* SELECT, WHERE, ORDER BY, LIMIT, DISTINCT, LIKE, BETWEEN
* GROUP BY and aggregate functions (COUNT, SUM)
* Window functions (RANK, running total, moving average)
* JOINs (LEFT JOIN, multi-table JOIN)

## Tools

* MySQL
* MySQL Workbench

## Project Files

* `queries.sql` - all SQL queries used in the project
* `Capstone_Project.docx` - full project report with output screenshots

## Key Queries

* Rank bookings for each customer by booking date
* Running total of revenue
* Moving average of the last 3 payments
* Total earnings generated by each driver
